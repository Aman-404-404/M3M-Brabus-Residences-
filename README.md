# M3M BRABUS Residences Website

A premium luxury real estate landing page developed using **React.js, Vite, and Tailwind CSS**. This project was created as part of a technical evaluation to showcase a modern, responsive, and visually engaging luxury property website. It features a clean and elegant user interface, smooth animations, responsive layouts, and well-structured components to deliver an enhanced user experience across desktop, tablet, and mobile devices.
